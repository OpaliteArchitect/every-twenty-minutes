# Every Twenty Minutes

A simple desktop utility app enforcing the 20-20-20 rule to reduce eye strain. Every 20 minutes, it prompts you to look at something 20 feet away for 20 seconds.

## Setup

1. Go to [**Releases**](https://github.com/OpaliteArchitect/every-twenty-minutes/releases).
2. Download `EveryTwentyMinutes.7z`.
3. Unzip the archive.
4. Open `EveryTwentyMinutes.exe`.
